# ArbScreenerBot — скрининг арбитражных монет (Binance / KuCoin / HTX)

## Назначение

Это НЕ боевой торговый бот. Это инструмент разведки: прогоняет широкий
список монет (115 шт) через три биржи, копит статистику по каждой монете
(сколько раз давала сигнал, средняя/лучшая маржа, симулированный P&L) —
и по итогам нескольких дней работы через `/leaderboard` ты видишь, какие
монеты реально стабильно дают спред между этими тремя площадками. Именно
эти монеты потом переносим в отдельного боевого бота (по образцу
`arb_bot_final.py`) для реальной торговли с настоящими API-ключами.

Бот **не отправляет реальных ордеров** ни в каком режиме — это часть
дизайна, не недоработка: на этапе скрининга деньги трогать не нужно.

## Биржи

- **Binance** — через `data-api.binance.vision` (обходит блокировку 451 на облачных IP типа Railway)
- **KuCoin** — прямой публичный API
- **HTX** (бывш. Huobi) — прямой публичный API
- **Bybit намеренно не включён** — подтверждённо блокирует облачные IP через CloudFront (403), без VPS/прокси не лечится

## Монеты (115 шт, категориями)

Топ-майоры, L2/новые сети, DeFi, AI-токены, мем-коины, игры/NFT, другие
L1, инфраструктура/индексация, разное — полный список в начале файла
`arb_screener_bot.py`, переменная `SYMBOLS`. Часть монет может
отсутствовать на одной-двух биржах — это нормально, такие просто не
попадут в сравнение (нужно данные минимум с 2 бирж одновременно).

## Параметры симуляции (как просил)

| Параметр | Значение | Переменная |
|---|---|---|
| Стартовый капитал (справочно) | 10 000 USDT | `START_CAPITAL` |
| Лот / шаг сделки | 100 USDT | `LOT_USDT` |
| Стоп-лосс | -50 USDT | `STOP_LOSS_USDT` |
| Порог маржи для сигнала | 0.15% | `MIN_PROFIT_PCT` |
| Лимит сделок в минуту | 5 | `MAX_TRADES_PER_MIN` |

Стоп-лосс работает так же, как в предыдущих ботах: при накопленном P&L
≤ -50 USDT торговля (запись новых сделок в P&L) автоматически
приостанавливается, сигналы дальше идут только справочно — включить
обратно можно только командой `/resume`, никакого автосброса по таймеру.

## Команды

```
/start          — запустить мониторинг в этом чате
/scan           — скан всех 115 монет по 3 биржам прямо сейчас
/top            — топ-20 пар по спреду (даже ниже порога — для разведки)
/prices SYMBOL  — bid/ask по конкретной монете на всех 3 биржах
/exchanges      — диагностика: сколько монет реально отдаёт каждая биржа
/leaderboard    — рейтинг монет-кандидатов на реальную торговлю
/stats          — общая статистика сессии
/history        — последние 10 сделок
/resume         — снять паузу после стоп-лосса
/setprofit 0.15 — изменить порог маржи
/setlot 100     — изменить размер лота
```

`/leaderboard` — главная команда для этой задачи. Сортирует монеты по
количеству сигналов за сессию, показывает число сделок, накопленный P&L
и лучшую замеченную маржу по каждой. Смотри её раз в день-два, а не в
первый час работы — статистика на коротком окне ненадёжна (см. историю
с предыдущим ботом, где за один вечер выбрали 5 монет, а на следующий
день 4 из них замолчали).

## Деплой (Railway, как остальные боты)

1. Файлы: `arb_screener_bot.py`, `requirements.txt`, `.python-version`.
2. Start Command: `python arb_screener_bot.py` (или переименуй в `main.py`,
   если так настроено в Railway — см. историю с прошлыми деплоями, где
   Railway продолжал запускать старый файл по забытому имени в Start Command).
3. Variables → `ARB_BOT_TOKEN` обязателен, остальное по желанию.
4. После деплоя сразу `/exchanges` — проверить, что все 3 биржи живые
   (Binance/KuCoin/HTX должны показать не 0 монет).

## Что дальше

Дай боту поработать минимум 2-3 дня (лучше неделю) без вмешательства,
периодически проверяя `/leaderboard`. Монеты, которые стабильно
появляются в топе несколько дней подряд (а не разово за один вечер) —
кандидаты на перенос в боевого бота с реальными API-ключами.
